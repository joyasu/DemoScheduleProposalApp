# DemoScheduleProposalApp

予定と予定の間の「移動」と「休憩」まで考えられる、スケジュール管理のデモアプリです。

「次の約束に間に合うかな？」「移動したあと、少し休めるかな？」といった疑問を、予定の時間と場所をもとに確認できます。外出や用事が続く日の計画づくりに役立ちます。

## できること

- **予定をまとめて管理**：タイトル、開始・終了日時、場所、メモを登録できます。終日の予定にも対応し、登録後の編集や削除もできます。
- **日ごとの予定を確認**：予定を一覧で見ながら、一日の流れを確認できます。済んだ予定には完了の印を付けられます。
- **行き先を検索**：店名・駅名・住所などから場所を探して、予定に設定できます。持ち物などはメモに残せます。
- **車での移動時間を確認**：予定の間を選ぶと、次の場所までの移動に必要な時間を調べます。現在地から次の予定への移動も確認できます。
- **休憩の余裕を確認**：移動後に時間があれば、次の予定の準備時間を考慮して休憩を提案します。間に合わない場合や、準備時間が少ない場合も知らせます。

## 基本の使い方

1. **「＋」から予定を追加します。** タイトルと日時を入力し、必要に応じて場所やメモを設定して「保存」を押します。
2. **予定一覧で一日の流れを確認します。** 登録した予定を選ぶと、内容を編集できます。
3. **きらきらマークのボタンを押します。** 移動や休憩を確認したい、予定と予定の間を選びます。複数の区間を選ぶこともできます。
4. **「実行」を押して提案を確認します。** 移動の出発・到着時刻や、休憩できる時間が表示されます。

## たとえば、こんな日に

午前中の用事が終わったあと、別の場所で午後の約束がある日。両方の予定に時間と場所を登録して、その間の区間を選ぶと、車での移動にどれくらい時間がかかり、到着後に休憩できるかを確認できます。

## 提案を使うときのポイント

- 移動時間の提案は**車での移動**が対象です。
- 移動時間を調べるには、場所の検索結果から行き先を選んでください。場所の名前だけを自由入力した場合は、提案時に場所の設定が必要です。
- 現在地からの提案を使う場合は、位置情報の利用を許可してください。
- 休憩は、次の予定の**10分前を準備の開始時刻**として、到着後に**5分以上**の余裕がある場合に提案されます。
- 提案は確認用です。**移動や休憩が予定に自動保存されることはありません。**
- 移動時間は目安です。通信状況や経路によっては、提案を取得できないことがあります。
